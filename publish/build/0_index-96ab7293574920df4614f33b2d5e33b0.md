## Chapter motivation (reference material, to be rewritten)

<!-- source: 4_1_introduction.md paragraphs 2-4 and closing paragraph. Kept as
     raw prose until the two-way hook above is written. -->

As computing power and storage became cheaper, researchers tried new ways to improve retrieval. They used natural language processing to match similar terms, for example matching synonyms such as "car" and "automobile" when one appears in a query and the other in a document. They tried new token definitions to handle spelling errors and OCR mistakes, for example using sub-word tokens. They also treated fixed phrases or n-grams like "New York" or "mother tongue" as single units, because the individual words mean something different. All these methods aimed to increase recall, that is, to find more of the relevant documents in the collection. However, they can also add noise and lower precision, requiring extra steps to re-rank the documents to match the user's intent.

An important point is that Natural Language Processing (NLP) can be applied to both documents and user queries, but the approaches differ because they serve different roles. Document processing usually normalizes and enriches text to make the collection ready for efficient search. Query processing focuses on understanding user intent and expanding or reformulating terms on the fly to retrieve all relevant results. Knowing these differences helps you tailor NLP to improve retrieval quality.

Modern retrieval goes further by using dense embeddings, which are vector representations of words, phrases, or documents produced by neural models. These embeddings capture semantic similarity beyond simple keyword matching. Semantic search methods can raise recall and improve understanding of meaning. In this chapter, however, the focus remains on NLP methods. Embeddings and semantic search are discussed in a later chapter.

In this chapter, we look at different approaches for advanced text processing, excluding for now the use of semantic search methods discussed in a later chapter. The main goal of all text processing, including semantic search methods, is to increase the retriever's recall while not adding too much noise for the ranker.

In traditional information retrieval, results depend on the exact query words. For example, if a user searches for "cat" images, the system returns only images labeled "cat". This lowers recall because relevant items that use different word forms are missed.

- One simple improvement is stemming or lemmatization. These methods normalize words to their root forms. Applying stemming to the earlier example lets the retrieval system return images tagged with "cats" as well as "cat". This increases recall by finding more relevant images. It can also add noise. For example, images showing multiple cats may appear even if the user wanted exactly one cat, which can reduce precision.

- Another approach uses linguistic relationships between words. Words can be expanded with synonyms, hypernyms, or hyponyms. For example, "cat" is a hyponym of "feline", and "feline" is the hypernym. Expanding a query to include "feline" broadens the search and can increase recall. However, this also adds noise: results may include images of tigers, lions, or other felines that do not match the user's original intent, reducing precision.

- Modern search methods go further with semantic search. They use word embeddings to capture learned relationships between terms. A query for "cat" can return images tagged with semantically related words, even when they are not exact matches. For example, images labeled "kitty" or related pets such as "dog" might appear in the results. Semantic search can greatly improve recall by finding relevant items beyond exact matches, but it can also add unrelated items and lower precision.

In summary, query expansion, whether through stemming, linguistic relationships, or semantic embeddings, improves recall by broadening the search space. Each method can lower precision by adding noise. Effective retrieval systems must balance these approaches to optimize both recall and precision according to the user's intent.
