Frameworks and Libraries

  - OpenSoundscape: https://opensoundscape.org/  is a Python library for audio manipulation and analytics

  - Librosa (http://librosa.github.io/librosa/) is a Python library for advances audio and music analysis. It provides base algorithms to create music retrieval systems.

  - OpenAI Whisper (https://github.com/openai/whisper) is a transformer based transcriber
