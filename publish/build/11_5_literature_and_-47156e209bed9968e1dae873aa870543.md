Frameworks and Libraries

  - OpenCV (https://opencv.org) is an advanced computer vision library original written for C/C++. But there are also bindings for Python, Java, and other languages.

  - scikit-image (http://scikit-image.org) is an advanced computer vision library written in Python. It provides all basic image manipulation operations as well as advanced feature extraction algorithms
