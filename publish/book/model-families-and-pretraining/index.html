Model Families and Pretraining

Where this is used

Transformer Embeddings explains self-attention, positional encodings, the transformer architecture, and the pretraining of BERT; this section starts where it stops. The embedding models of Semantic Similarity with Transformers and Building Semantic Search are encoders or decoders from the families below, fine-tuned with contrastive losses. The language models of 7 - Retrieval Augmented Generation are decoders, Whisper in Transcription is an encoder-decoder, and CLIP in Multimodal Transformers pairs two encoders.

Hundreds of transformer models exist, but they fall into three families that differ in which tokens may attend to which, and they are pretrained with a handful of self-supervised objectives. This section describes the three families, the pretraining objectives, the most important models since BERT, and the changes to the architecture that today’s models share. Together, they explain why one model suits classification, another generation, and a third transcription.

Three Families¶

The transformer of 2017 had two halves: an encoder that reads the input and a decoder that generates the output, as Transformer Embeddings shows. Later models use either half alone or both.

Encoder-only models, such as BERT, let every token attend to every other token in both directions. They compute one contextualized vector per input token and are suited to understanding tasks: classification, named entity recognition, and the embeddings of semantic search. They cannot generate text, since every position sees the whole input.

Decoder-only models, such as GPT, Llama, and Qwen, let each token attend only to itself and the tokens before it. This causal attention makes them generators: they predict the next token from the previous ones, append it, and repeat (Generative Language Models). Today’s large language models are decoders, and decoders increasingly serve as embedding models too, using the vector of the last token instead of [CLS].

Encoder-decoder models, such as T5, BART, and Whisper, keep both halves. The encoder reads the whole input bidirectionally; the decoder generates the output causally and attends to the encoder’s vectors through cross-attention. They suit tasks that transform one sequence into another: translation, summarization, and speech recognition, where the input is audio and the output text.

The difference between the families is a mask in the attention. Attention computes scores between all pairs of positions and turns each row into weights with a softmax. A mask adds −∞-\infty−∞ to the scores of the forbidden pairs, so that their weights become exactly zero:

Example: Causal attention over four tokens

For the input “the cat sat down”, an encoder computes attention weights for all 4⋅4=164 \cdot 4 = 164⋅4=16 pairs. A decoder computes them only for the pairs with j≤ij \le ij≤i: “the” attends to itself, “cat” to “the” and itself, “sat” to three tokens, “down” to all four, which makes 1+2+3+4=101 + 2 + 3 + 4 = 101+2+3+4=10 pairs. The vector of “cat” therefore cannot depend on “sat” or “down”. This is what allows a decoder to be trained on predicting every next token of a text at once: each position computes its prediction without seeing the token it predicts.

Pretraining Objectives¶

All three families are first pretrained on large text collections with self-supervised objectives, which take their targets from the text itself (Self-Supervised Learning), and only then adapted to a task.

Masked language modeling (MLM) trains encoders. BERT selects 15% of the tokens and predicts them from the context. To avoid a mismatch with fine-tuning, where no [MASK] tokens occur, it replaces 80% of the selected tokens with [MASK], 10% with a random token, and keeps 10% unchanged. RoBERTa (2019) showed that BERT was undertrained: dropping the next-sentence task, choosing new masks in every epoch, and training longer on ten times more data improved every benchmark. ELECTRA (2020) replaces masked prediction with replaced token detection: a small generator fills in masked tokens, and the encoder learns to tell for every token whether it is original or replaced, so it learns from all tokens instead of 15% of them.

Causal language modeling trains decoders. The model predicts each token from the tokens before it, and the loss is the cross-entropy of Cross-Entropy summed over all positions:

The negative log probability of each actual next token, given everything before it. Thanks to the causal mask, one forward pass computes the predictions for all TTT positions of a training text at once.

For example, the small language model SmolLM2-135M assigns the probability 0.096 to " Bern" as the next token after “The capital of Switzerland is”, so this position contributes −ln⁡0.096=2.34-\ln 0.096 = 2.34−ln0.096=2.34 to the loss. Training on trillions of tokens drives such probabilities up for the tokens that actually follow.

Span corruption trains the encoder-decoder T5 (2019). It replaces random spans of the input with sentinel tokens and lets the decoder generate the missing spans. T5 casts every task as text to text, so that translation, classification, and summarization share one model and one loss. Denoising trains BART (2019): the input is corrupted by masking, deleting, and permuting, and the decoder reconstructs the original. Contrastive objectives train embedding models and multimodal models: they pull matching pairs together and push the other pairs of a batch apart, as in the multiple negatives ranking loss of Semantic Similarity with Transformers and the image-text training of CLIP in Multimodal Transformers.

Distillation produces smaller models from larger ones. A small student model is trained to reproduce the output distributions of a large teacher instead of the hard labels. DistilBERT (2019) is 40% smaller than BERT and 60% faster while keeping 97% of its language understanding.

Architecture Changes Since 2017¶

The transformers of today differ from the original in several details that make them more stable, faster, and able to handle longer inputs. The small model SmolLM2-135M, with 30 layers, a vocabulary of 49,152 tokens, and a context of 8,192 tokens, uses all of the first four.

Pre-normalization. The original transformer normalized after each sublayer and its residual connection. Moving the layer normalization of Training Deep Networks before the sublayer keeps the residual path free of normalization and makes deep transformers train stably; most models also use the simpler RMSNorm, which rescales without subtracting the mean.

Rotary position embeddings (RoPE). Instead of adding a position vector to each token, RoPE rotates the query and key vectors by an angle that grows with the position. The dot product of a query and a key then depends on their distance, not on their absolute positions, which helps models generalize to sequences longer than those seen in training.

Gated feed-forward layers. The feed-forward layer between the attention layers uses a gated activation such as SwiGLU, which multiplies one linear projection component by component with the activation of another and works better than a plain ReLU or GELU layer at the same cost.

Grouped-query attention (GQA). During generation, a decoder stores the keys and values of all previous tokens, the KV cache of Generative Language Models, so that it does not recompute them for each new token. GQA lets several query heads share one key and value head, which shrinks the cache. SmolLM2-135M has 9 query heads that share 3 key and value heads.

Example: The size of the KV cache

An 8B model with 32 layers and attention heads of dimension 128 stores two vectors, a key and a value, per layer and key-value head for each token, in 16-bit numbers. With 32 key-value heads, one per query head, this is 2⋅32⋅32⋅128⋅22 \cdot 32 \cdot 32 \cdot 128 \cdot 22⋅32⋅32⋅128⋅2 bytes =512= 512=512 KiB per token, or 4 GiB for a context of 8,192 tokens. With grouped-query attention and 8 key-value heads, as in Llama 3 8B, it is 128 KiB per token and 1 GiB for the same context: four times more conversations fit into the memory of one graphics processor.

Efficient attention kernels. Attention over nnn tokens computes an n×nn \times nn×n matrix of scores. FlashAttention computes exact attention in tiles that fit into the fast on-chip memory of a graphics processor and never stores the full matrix, which makes the memory grow linearly with the sequence length and the computation several times faster.

Mixture of experts (MoE). A mixture-of-experts layer contains several feed-forward networks, the experts, and a small router that sends each token to a few of them. The model has many parameters, but each token uses only a fraction. Mixtral 8x7B has 47 billion parameters, but each token activates only 13 billion; several Qwen3 models use the same design.
