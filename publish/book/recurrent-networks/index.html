Recurrent Networks

Where this is used

Transformer Embeddings explains why transformers replaced recurrent networks for text: a recurrent network processes a sequence one step at a time, and its hidden state degrades over long distances even with LSTM and GRU cells. This section describes these networks and cells. Before transformers, recurrent networks also turned sequences of acoustic features into phonemes in speech recognizers, the step that Transcription now assigns to transformer models.

Text, speech, and video are sequences, and their meaning depends on order and context. A fully connected or convolutional network expects an input of fixed size. A recurrent network instead processes a sequence one element at a time and carries a state from one step to the next, so that each output can depend on everything the network has seen before. This section describes the basic recurrent network, explains why it is hard to train, and introduces the gated cells that solved the problem and the attention mechanism that eventually replaced recurrence.

Unrolling a Recurrent Network¶

At each time step ttt, a recurrent network combines the current input xt\mathbf{x}_txt​ with its previous hidden state ht−1\mathbf{h}_{t-1}ht−1​ into a new hidden state, from which it can compute an output yt\mathbf{y}_tyt​:

Key Formula: Recurrent Network
ht=tanh⁡(Wh ht−1+Wx xt+b),yt=Wy ht+c\mathbf{h}_t = \tanh\bigl(\mathbf{W}_h\, \mathbf{h}_{t-1} + \mathbf{W}_x\, \mathbf{x}_t + \mathbf{b}\bigr), \qquad \mathbf{y}_t = \mathbf{W}_y\, \mathbf{h}_t + \mathbf{c}ht​=tanh(Wh​ht−1​+Wx​xt​+b),yt​=Wy​ht​+c
(1)

The hidden state summarizes the sequence up to step ttt. The same weights Wh\mathbf{W}_hWh​, Wx\mathbf{W}_xWx​, and Wy\mathbf{W}_yWy​ are used at every step.

Figure 1 shows the network unrolled in time: a chain of copies of the same cell AAA, one per time step, each passing its hidden state to the next. Unrolled, a recurrent network is a deep feed-forward network with one layer per time step and with weights shared across all layers. It is trained like one, with backpropagation over the unrolled graph, which is called backpropagation through time. Since the weights are shared, their gradients add up the contributions of all time steps, like the shared bias of Backpropagation and Gradient Descent.

A recurrent network can map a sequence to a single output, for example a sentiment label for a sentence; to a sequence of the same length, for example one phoneme per audio frame; or, as the encoder-decoder below shows, to a sequence of a different length. A bidirectional network runs one recurrent network forward and one backward over the sequence and combines their hidden states, so that each position sees the context on both sides.

Gradients Through Time¶

The depth of an unrolled network equals the length of the sequence, and long sequences make the gradient problems of Training Deep Networks severe. In the backward pass, the gradient that reaches step ttt from step TTT has passed through T−tT - tT−t multiplications with the same matrix Wh\mathbf{W}_hWh​ and with the derivatives of the activation function.

With w=0.9w = 0.9w=0.9, this is at most 0.950=0.0050.9^{50} = 0.0050.950=0.005: what the network saw 50 steps ago has almost no influence on the gradient. With w=1.1w = 1.1w=1.1 and the unit in its linear range, the factor can reach 1.150=1171.1^{50} = 1171.150=117, and the gradient explodes.

Exploding gradients are easy to contain with gradient clipping, which rescales the gradient whenever its norm exceeds a threshold. Vanishing gradients are the harder problem, because they prevent the network from learning dependencies over long distances, such as the agreement between a subject and a verb many words later.

LSTM and GRU Cells¶

The long short-term memory (LSTM) cell of Hochreiter and Schmidhuber (1997) adds a second state, the cell state ct\mathbf{c}_tct​, and three gates that control it. Each gate is a layer of sigmoid neurons that computes values between 0 and 1 from the input and the previous hidden state, and it multiplies another vector component by component:

  • the forget gate ft\mathbf{f}_tft​ decides how much of the old cell state to keep,

  • the input gate it\mathbf{i}_tit​ decides how much of a new candidate c~t\tilde{\mathbf{c}}_tc~t​ to add,

  • the output gate ot\mathbf{o}_tot​ decides how much of the cell state appears in the hidden state.

Key Formula: LSTM Cell State
ct=ft⊙ct−1+it⊙c~t,ht=ot⊙tanh⁡(ct)\mathbf{c}_t = \mathbf{f}_t ⊙ \mathbf{c}_{t-1} + \mathbf{i}_t ⊙ \tilde{\mathbf{c}}_t, \qquad \mathbf{h}_t = \mathbf{o}_t ⊙ \tanh(\mathbf{c}_t)ct​=ft​⊙ct−1​+it​⊙c~t​,ht​=ot​⊙tanh(ct​)
(2)

The cell state is updated by addition instead of by a matrix product and a squashing function. Its gradient flows back through the forget gate alone, so information and gradients can travel over many steps when the forget gate stays close to 1.

With a forget gate of 0.99, the cell state keeps 0.9950=0.610.99^{50} = 0.610.9950=0.61 of its content after 50 steps, where the scalar recurrent network above kept at most 0.005 of its gradient. The network learns when to keep and when to forget: the gates are trained with the rest of the network. The gated recurrent unit (GRU) of Cho and colleagues (2014) simplifies the LSTM to two gates, an update gate and a reset gate, and merges the cell state into the hidden state. It has fewer parameters and often performs as well.

From Recurrence to Attention¶

For translation, an encoder-decoder architecture uses two recurrent networks. The encoder reads the source sentence and summarizes it in its final hidden state; the decoder starts from this state and generates the target sentence one word at a time, each step taking the previous word as input. A single vector must then hold the whole sentence, and translations of long sentences degrade. Bahdanau, Cho, and Bengio (2015) let the decoder look back at all hidden states of the encoder: at each step, it computes a weighted average of them, with weights that indicate which source words matter for the next target word. This mechanism is called attention.

The transformer of 2017 kept attention and dropped recurrence. Its self-attention connects every position directly with every other one, so information no longer has to pass through a chain of hidden states, and all positions can be computed in parallel instead of one after the other. Transformer Embeddings explains the architecture. Recurrent networks remain useful where a sequence arrives step by step and memory is limited, for example in speech recognition on small devices, and the idea of a compact state updated at every step returns in recent state-space models such as Mamba, which process very long sequences in time linear in their length.
