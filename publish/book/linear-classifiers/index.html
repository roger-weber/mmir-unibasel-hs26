Linear Classifiers: Logistic Regression and Support Vector Machines

Where this is used

trains a logistic regression on frozen image embeddings, a linear probe, and classifies HOG descriptors with a support vector machine. Automated Feature Extraction names decision trees and support vector machines as the standard classifiers of the two decades before deep learning. Evaluating Text Classifiers evaluates multi-class classifiers one class against the rest, the same decomposition that turns binary classifiers into multi-class ones below.

A linear classifier decides by the sign of a weighted sum, w⊤x+b\mathbf{w}^\top \mathbf{x} + bw⊤x+b: examples on one side of the hyperplane w⊤x+b=0\mathbf{w}^\top \mathbf{x} + b = 0w⊤x+b=0 belong to one class, examples on the other side to the other. The perceptron of From Perceptrons to Multilayer Networks is the simplest linear classifier, and it accepts any hyperplane that separates the training data. This section describes two methods that choose the hyperplane more carefully. Logistic regression turns the weighted sum into a probability and fits it with the cross-entropy loss. The support vector machine chooses the hyperplane with the largest distance to the nearest examples, and with the kernel trick, it separates classes that no hyperplane in the original space can separate.

Logistic Regression¶

Logistic regression models the probability of the positive class with the sigmoid of the weighted sum, the function of a single neuron in From Perceptrons to Multilayer Networks:

With KKK classes, the sigmoid becomes the softmax of Softmax, and the model computes one weighted sum per class: softmax regression, a network with a single layer. The linear probe of is such a model on top of fixed embeddings. Like all linear models, logistic regression overfits when there are many features and few examples, which the L2 penalty of Training Deep Networks prevents.

Logistic regression and Naive Bayes (Naive Bayes) solve the same task in two different ways. Naive Bayes is generative: it models how each class produces its features and derives the decision from Bayes’ rule. Logistic regression is discriminative: it models the decision boundary directly and makes no assumption about how the features are distributed. Ng and Jordan (2002) showed that Naive Bayes reaches its best accuracy with fewer training examples, while logistic regression is more accurate when many examples are available.

Support Vector Machines¶

When the classes are linearly separable, infinitely many hyperplanes separate them. Figure 1 contrasts two of them. The perceptron stops at the first one it finds. The support vector machine (SVM), developed by Vapnik and colleagues in the 1990s, chooses the hyperplane with the largest margin, the distance to the nearest training examples on either side. A large margin leaves the most room for new examples that lie a little closer to the other class than the training examples did.

We label the classes yi=+1y_i = +1yi​=+1 and yi=−1y_i = -1yi​=−1 and scale w\mathbf{w}w and bbb so that the nearest examples satisfy yi(w⊤xi+b)=1y_i(\mathbf{w}^\top \mathbf{x}_i + b) = 1yi​(w⊤xi​+b)=1. The margin then has the width 2/∥w∥2 / \lVert \mathbf{w} \rVert2/∥w∥, and maximizing it means minimizing ∥w∥\lVert \mathbf{w} \rVert∥w∥ while every example lies on the correct side, outside the margin. Real data is rarely separable, so the soft-margin SVM allows violations and penalizes them with the hinge loss:

The first term widens the margin, the second penalizes examples that lie inside the margin or on the wrong side. The hyperparameter CCC sets the trade-off: a large CCC tolerates few violations, a small CCC prefers a wide margin.

The examples that lie on the margin or violate it are the support vectors. Only they determine the solution: moving or removing any other example does not change the hyperplane. Unlike the perceptron rule, the SVM solves a convex optimization problem with a single optimum.

The Kernel Trick¶

A linear classifier cannot separate classes that are not linearly separable, such as the XOR of From Perceptrons to Multilayer Networks. The remedy is to map the examples into a higher-dimensional space with a nonlinear function ϕ\phiϕ, in which a hyperplane separates them. For XOR with the inputs coded as ±1\pm 1±1, the product x1x2x_1 x_2x1​x2​ is enough: it is +1 when both inputs agree and -1 when they differ, so a single threshold on this new feature separates the classes.

The mapped space can be very large. The SVM, however, needs the examples only in dot products ϕ(x)⊤ϕ(x′)\phi(\mathbf{x})^\top \phi(\mathbf{x}')ϕ(x)⊤ϕ(x′), both for training and for classifying, when the optimization is written in its dual form. A kernel K(x,x′)K(\mathbf{x}, \mathbf{x}')K(x,x′) computes this dot product directly from the original vectors, without ever computing ϕ\phiϕ. This is the kernel trick.

The Gaussian kernel K(x,x′)=exp⁡(−γ∥x−x′∥2)K(\mathbf{x}, \mathbf{x}') = \exp(-\gamma \lVert \mathbf{x} - \mathbf{x}' \rVert^2)K(x,x′)=exp(−γ∥x−x′∥2) corresponds to a mapping into a space with infinitely many dimensions and can separate almost any training set; its width γ\gammaγ and the penalty CCC are tuned on validation data. The kernel trick is powerful, but choosing a good kernel is a design decision made by a human, much like choosing hand-crafted features, and training an SVM costs between quadratic and cubic time in the number of examples. For very large datasets, linear models and neural networks, which learn their features, took over.

From Binary to Multi-Class¶

The perceptron and the SVM separate two classes. Two strategies combine binary classifiers into a classifier for KKK classes. One-vs-rest trains KKK classifiers, each separating one class from all others, and predicts the class whose classifier gives the highest score. One-vs-one trains K(K−1)/2K(K-1)/2K(K−1)/2 classifiers, one per pair of classes, and predicts the class that wins the most pairwise decisions; with 10 classes, this means 45 classifiers, each trained on the examples of two classes only. Logistic regression extends naturally to many classes with the softmax and needs neither strategy.
