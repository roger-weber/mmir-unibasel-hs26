Convolutional Networks

Where this is used

Classifying Audio applies convolutional networks to spectrograms, which they treat like images. The receptive fields of the retina in The Human Visual System inspired the design, and CNN Architectures walks through the architectures built from these layers.

A fully connected layer connects every input to every neuron. For images, this is wasteful in two ways. It needs an enormous number of weights, and it ignores that pixels close to each other belong together and that a pattern means the same wherever it appears. Convolutional networks build these two assumptions into their layers. This section introduces the convolutional layer, the strides and padding that control its output size, pooling, the 1×11 \times 11×1 convolution, and the way a stack of these layers ends in a classifier.

Local Receptive Fields and Shared Weights¶

Our eyes analyze a scene with receptive fields, small regions of the retina whose cells respond to local patterns, and the same kind of field works at every position of the visual field. A convolutional layer copies this design. Each neuron of the layer connects only to a small neighborhood of the input, for example 5×55 \times 55×5 pixels, as Figure 1 shows. The layer contains one such neuron for every position of the input, and all of them share the same weights and the same bias.

Earlier systems prepared images for learning with hand-designed filters, such as Gaussian smoothing, Sobel gradients, or HOG descriptors, and fed the results into a network. This limited what the network could learn, and filters chosen for one task did not necessarily transfer to the next. A convolutional layer learns its filters from the data instead.

Sharing the weights has three consequences. The layer computes the same feature at every position, so a pattern is detected wherever it appears. The number of parameters is small and independent of the image size. And every weight receives an update from every position in each backward pass, since the shared weights collect the deltas of all positions like the shared bias in Backpropagation and Gradient Descent. In a 1024×10241024 \times 10241024×1024 layer, a single example contributes more than a million terms to the gradient of each kernel weight.

An image has several input channels, three for an RGB image, and a layer computes several output features, the feature maps. Figure 2 shows the computation for one position: the kernel covers a neighborhood in all input channels, and each output feature has its own kernel and bias.

A 5×55 \times 55×5 grayscale patch has the value 10 in its three left columns and 80 in its two right columns, a vertical edge. Strides and Padding¶

The kernel slides over the input with a stride sss, the distance between two consecutive window positions. A stride of 1 computes an output at every position; a stride of 2 skips every other position in both directions and produces a quarter of the outputs. Padding adds ppp rows and columns of zeros around the input, so that the kernel can also be centered on the border pixels. Kernels usually have an odd size kkk, so that they have a center.

A 32×3232 \times 3232×32 input with a 3×33 \times 33×3 kernel, stride 1, and padding 1 gives ⌊(32+2−3)/1⌋+1=32⌊(32 + 2 - 3)/1 ⌋ + 1 = 32⌊(32+2−3)/1⌋+1=32 outputs per dimension: the size is preserved. Strides reduce the size of the network’s layers early and let later layers compute features at a coarser scale.

Pooling¶

Convolutional layers are often followed by a pooling layer, which summarizes each small neighborhood of a feature map in a single value. Max pooling keeps the largest value of the neighborhood, as in Figure 3, and average pooling keeps the mean. Pooling has no parameters and no activation function, and it is applied to each feature map separately, so the number of features stays the same.

Example: Pooling a feature map

A 4×44 \times 44×4 feature map has the rows (1,3,2,0)(1, 3, 2, 0)(1,3,2,0), (4,6,1,1)(4, 6, 1, 1)(4,6,1,1), (0,2,5,7)(0, 2, 5, 7)(0,2,5,7), and (1,1,3,2)(1, 1, 3, 2)(1,1,3,2). Max pooling over 2×22 \times 22×2 windows with stride 2 gives the 2×22 \times 22×2 output with the rows (6,2)(6, 2)(6,2) and (2,7)(2, 7)(2,7); average pooling gives (3.5,1)(3.5, 1)(3.5,1) and (1,4.25)(1, 4.25)(1,4.25). Each dimension is halved, so the map has four times fewer values. Max pooling also makes the output insensitive to small shifts: the 6 in the top left window could move to any of the four positions of its window without changing the result.

Pooling reduces the spatial size only with a stride larger than 1. Global pooling reduces each feature map of the last convolutional layer to a single value, its maximum or its average. Global average pooling turns the output of the last convolutional layer into a vector with one value per feature, the image embedding that uses.

1 × 1 Convolutions¶

A convolution with a 1×11 \times 11×1 kernel looks at a single position. It does not combine neighboring pixels, but it combines the features at each position into new ones, like a fully connected layer applied to every pixel separately. Its main use is to reduce the number of features before an expensive convolution.

Example: Fewer parameters with a 1 × 1 convolution

A 5×55 \times 55×5 convolution from 20 input features to 20 output features needs 5⋅5⋅20⋅20=10,0005 \cdot 5 \cdot 20 \cdot 20 = 10{,}0005⋅5⋅20⋅20=10,000 weights and 20 biases, 10,020 parameters. A 1×11 \times 11×1 convolution can first reduce the 20 features to 3, with 20⋅3=6020 \cdot 3 = 6020⋅3=60 weights and 3 biases. The 5×55 \times 55×5 convolution from these 3 features to 20 outputs then needs 5⋅5⋅3⋅20=1,5005 \cdot 5 \cdot 3 \cdot 20 = 1{,}5005⋅5⋅3⋅20=1,500 weights and 20 biases. Together, the two layers have 1,583 parameters instead of 10,020, at the price of a compressed representation between them. The inception modules of GoogLeNet in CNN Architectures are built on this idea.

From Feature Maps to Classes¶

Figure 4 shows how the layers combine in an image classifier. Convolutional layers with activation functions alternate with pooling layers. With each stage, the feature maps become smaller and more numerous, and each neuron sees a larger part of the image: two stacked 3×33 \times 33×3 convolutions already cover a 5×55 \times 55×5 region of the input, so deep layers respond to object parts and whole objects instead of edges. At the end, a flattening layer turns the last feature maps into one long vector, and fully connected layers with a softmax output compute the class probabilities.

Flattening ties the network to one input size, because the length of the vector depends on the size of the feature maps. Modern architectures replace it with global average pooling, which produces one value per feature map for any input size, followed by a single fully connected layer. CNN Architectures follows this development from LeNet to ResNet.
