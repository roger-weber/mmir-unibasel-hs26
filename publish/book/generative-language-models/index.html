Generative Language Models

Where this is used

The retrieval-augmented generation of 7 - Retrieval Augmented Generation and the agents of Agentic RAG are built around generative language models, and Multimodal Transformers uses them to describe images and names hallucination as the eighth obstacle of content analysis. Text Classification classifies text with a prompt that asks for JSON output. This section explains how these models produce text, why they sometimes produce wrong text fluently, and what the context window and the KV cache cost.

A generative language model is a decoder (Model Families and Pretraining) pretrained to predict the next token. Generating text is nothing more than repeating this prediction: the model computes a probability distribution over its vocabulary, one token is chosen, it is appended to the input, and the model predicts again. How the token is chosen matters a great deal. The same model can be deterministic or creative, repetitive or varied, depending on its decoding strategy. This section follows the loop with a small open model, SmolLM2-135M-Instruct, whose 135 million parameters run on a laptop processor at about 26 tokens per second.

Generating Text Token by Token¶

For a given input, the model outputs one logit per token of its vocabulary, 49,152 for SmolLM2, and the softmax of Softmax turns them into probabilities. For the input “The capital of Switzerland is”, the five most probable next tokens are:

Next token" the"" Geneva"" Bern"" located"" called"
Probability0.2430.1040.0960.0930.043

The model does not look up a fact. It has learned which continuations are likely after such a sentence, and many continuations are: “the city of ...”, a city name, “located in ...”. The correct answer, Bern, has slightly less probability than Geneva, which is wrong. A larger model trained on more data concentrates more probability on Bern, but the principle stays the same: the output is drawn from a distribution over plausible text.

Decoding Strategies¶

Greedy decoding always chooses the most probable token. It is deterministic, but it tends to produce bland and repetitive text, and a locally best token can lead into a poor continuation. Beam search keeps the kkk most probable partial sequences instead of one and chooses the best complete sequence; it is common in translation and speech recognition, where one correct output is expected.

Sampling draws the next token at random from the distribution, so the same input can produce different outputs. Two parameters shape the distribution before sampling. The temperature τ\tauτ of Softmax divides the logits: a temperature below 1 sharpens the distribution toward the most probable tokens, a temperature above 1 flattens it. Top-p sampling, also called nucleus sampling, keeps only the smallest set of tokens whose probabilities add up to at least ppp and samples from them after renormalizing, which cuts off the long tail of implausible tokens. Top-k sampling keeps the kkk most probable tokens instead.

Such fluent but false statements are called hallucinations. They are not a malfunction but a consequence of the mechanism: the model produces likely text, and likely text is not always true. Larger models hallucinate less on common facts, but they still do so on rare facts, recent events, and questions outside their training data. This is the main reason why retrieval-augmented generation (7 - Retrieval Augmented Generation) gives the model the relevant documents and asks it to answer from them.

From Language Model to Assistant¶

A model pretrained on next-token prediction continues text; it does not follow instructions. Asked a question, it may continue with more questions. Turning it into an assistant takes two further training stages. Instruction tuning, a supervised fine-tuning on pairs of instructions and good responses, teaches the model to answer. Preference alignment then teaches it which of several possible answers people prefer. Reinforcement learning from human feedback (Tasks and Experience) trains a reward model on human rankings of answers and tunes the language model to maximize the reward; direct preference optimization (DPO) reaches a similar result with a simple classification loss on pairs of preferred and rejected answers, without a separate reward model.

An instruction-tuned model expects its input in a fixed chat template, a serialization of the conversation with special tokens that mark the roles. For SmolLM2, a request to classify the sentiment of “The battery died after two days.” becomes the text

<|im_start|>system
You are a helpful AI assistant named SmolLM, trained by Hugging Face<|im_end|>
<|im_start|>user
Classify the sentiment of this review as positive or negative: "The battery died after two days."<|im_end|>
<|im_start|>assistant

and the model continues after the last line with “The sentiment of this review is negative.” The template is part of what the model learned during instruction tuning; libraries apply it automatically, and a wrong template degrades the answers noticeably.

The Context Window and the KV Cache¶

The context window is the maximum number of tokens the model can attend to: 8,192 for SmolLM2, and between 128,000 and a million tokens for current large models. Everything the model should consider must fit into it: the system instructions, the conversation so far, retrieved documents, and the answer being generated. Longer contexts are not used uniformly. Liu and colleagues showed that models use information at the beginning and the end of a long context much better than information in the middle, a reason why Chunking Strategies cares about which passages enter the prompt and where.

Generation runs in two phases. In the prefill phase, the model processes the whole prompt in one parallel pass, like an encoder. In the decode phase, it generates one token at a time. To avoid recomputing the keys and values of all previous tokens at every step, it stores them in the KV cache and only computes the new token’s query, key, and value. The cache grows with every token, and for long contexts it, not the model weights, fills the memory of the graphics processor: Model Families and Pretraining computes 1 GiB per 8,192 tokens for an 8B model with grouped-query attention. Serving systems such as vLLM therefore manage the cache in fixed-size blocks, like the pages of an operating system, to fit more requests into memory.

In-Context Learning and Prompting¶

Large language models can learn a task from the prompt alone, without any change to their weights. A zero-shot prompt describes the task. A few-shot prompt adds a few solved examples, from which the model infers the pattern; GPT-3 showed in 2020 that this ability emerges with scale. Chain-of-thought prompting asks the model to write intermediate reasoning steps before the answer, which improves its accuracy on problems that need several steps, such as arithmetic word problems. Recent reasoning models are trained to produce such steps on their own.

Prompting has costs. A prompt adds tokens, and every token costs time and money. The output can vary from run to run, and small changes to the wording can change the result. For tasks with a fixed set of labels and enough training data, a fine-tuned classifier is often faster, cheaper, and more accurate (Text Classification).

Structured Output¶

Many applications need machine-readable output instead of prose, for example a JSON object with a label and extracted fields. A prompt can ask for JSON and describe its fields, but a model may still produce invalid JSON or invent fields. Constrained decoding guarantees the format: at each step, it sets the probability of every token to zero that would violate a grammar or a JSON schema, so the model can only generate valid output. Most serving systems and model APIs offer such structured output modes.

Confidence values in generated text are not probabilities

A model asked to output a confidence for each label writes numbers that look like probabilities but are just more generated text. In an earlier version of this material, a model classified the opening of Arthur Conan Doyle’s novel A Study in Scarlet as song lyrics with a confidence of 0.7 and justified this with a “repetitive, rhythmic structure” that the prose does not have. When calibrated scores are needed, the probabilities that the model assigns to the label tokens are a better basis, and they must still be checked on validation data, as Scores, Thresholds, and ROC Curves describes.
