# 0 - Why Retrieval Matters

You search for "heart disease symptoms" and Google returns pages about "cardiovascular conditions". You ask ChatGPT about a company's quarterly earnings and it pulls the answer from a 200-page PDF you uploaded. You hum a melody into your phone and Shazam names the song in seconds. These are all retrieval systems, and they solve a problem that has only grown harder as the world produces more data in more formats than any human could browse.

This course teaches you how such systems work: from the classical keyword matching that powered early search engines, through the statistical ranking models still running in production today, to the neural and multimodal systems that understand meaning across text, images, and audio.

```{admonition} What you'll learn
:class: tip
- Explain why keyword matching fails and how modern retrieval bridges the vocabulary gap
- Identify where a retrieval system sits on the spectrum from exact match to generative answer
- Navigate the structure of this course and connect each chapter to a concrete retrieval capability
```
