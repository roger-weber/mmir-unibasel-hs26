The table reads from top to bottom as the history of image features. The first generation measures what human vision responds to, colors, edges, and keypoints, with rules designed by hand. Each of these features was built for one task and solves it well, but it rarely transfers to another, and perceptual features find images that look alike, not images that show the same thing. The second generation learns its features from labeled photos. Training searches a far larger space of filters than a designer could try: its first layer rediscovers edge and Gabor filters, and its last layer yields an embedding that transfers to new tasks with a few labeled examples. Its vocabulary, however, is the fixed list of training classes. The third generation learns without class labels, from captions (CLIP) or from the images themselves (DINOv2). Captions name millions of concepts and describe whole scenes, so search no longer depends on a list of labels: a system can describe each image in text and search the text, compare text queries with images in one embedding space, or compare images with images. The newer features do not make the older ones useless: exact color constraints, verifiable matches of the same object, explainability, and cost still favor the classical features.

Key Takeaways¶

  1. The color space decides whether color distances make sense. Equal steps in sRGB are not equal to the eye; CIE Lab approximates perceived differences, and HSV separates the hue from the brightness.

  2. Color histograms and moments describe which colors occur, not where or what. Bin-by-bin distances react strongly to small shifts across bin boundaries; the quadratic distance accounts for similar reference colors.

  3. Gradients, Gabor filters, and HOG describe how intensities are arranged. SIFT finds distinctive keypoints and matches them across viewpoints with the ratio test, which makes it the tool for finding the same object, not the same category. Each hand-designed feature solves the task it was designed for, but rarely transfers to another.

  4. A CNN trained for classification learns filters that resemble hand-designed ones in its first layer. Learned features are not bound to the designer’s assumptions, and with labeled examples they adapt to a new domain. The network’s pooled last stage is an image embedding that transfers to new tasks with a frozen backbone and a linear probe, but its distances were not trained for comparison. Encoders trained with metric learning, the image counterpart of bi-encoders for text, compare images better.

  5. Class labels limit search to a fixed list and say nothing about how a scene is composed. Three paths go beyond labels: describe each image in text and search the text, compare texts and images in one embedding space (CLIP), and compare images with images in an embedding space trained for similarity (DINOv2 or CLIP).

  6. CLIP and DINOv2 embeddings are the basis of image search today: one encoder pass per image, a vector index, and queries by example or by text. Similarity values and thresholds are specific to each model and query type.

Exam focus

  • Why sRGB distances mislead, and what Lab and HSV each offer for color features.

  • Bin-by-bin distances versus the quadratic distance versus histogram intersection: which query type each serves, and why the quadratic distance needs the matrix A\mathbf{A}A.

  • Histograms and moments versus layout: what global color features cannot see, and one remedy.

  • What HOG and SIFT are invariant to, why SIFT finds the same object but not the same category, and why hand-designed features rarely transfer to a new task.

  • How a classifier becomes a feature extractor (global average pooling, second-to-last layer), the difference between a frozen backbone with a linear probe and fine-tuning, and why a classification embedding is not a similarity embedding (compare BERT and Sentence-BERT).

  • The three paths beyond class labels (text descriptions, a shared image-text space, image-to-image comparison), what CLIP and DINOv2 learn from, which queries each supports, and why similarity thresholds do not transfer between models.

  • How CLIP’s contrastive training works: the N×NN \times NN×N similarity matrix of a batch, the softmax over rows and columns, the role of the temperature, and why similarities between an image and a text stay low.

  8. (Evaluate) An online shop wants three functions: “show sweaters in exactly this red”, “find copies of our product photos on other websites”, and “find products that match the description ‘cozy winter sweater’”. Choose a feature for each function and justify the choice.

Further Reading¶

  • Swain, M. J., & Ballard, D. H. (1991). Color indexing. International Journal of Computer Vision, 7(1), 11-32. DOI. The paper that introduced color histograms with histogram intersection for object recognition.

  • Flickner, M., Sawhney, H., Niblack, W., Ashley, J., Huang, Q., Dom, B., Gorkani, M., Hafner, J., Lee, D., Petkovic, D., Steele, D., & Yanker, P. (1995). Query by image and video content: The QBIC system. IEEE Computer, 28(9), 23-32. DOI. IBM’s QBIC was the first commercial content-based image retrieval system, with color, texture, and shape features.

  • Hafner, J., Sawhney, H. S., Equitz, W., Flickner, M., & Niblack, W. (1995). Efficient color histogram indexing for quadratic form distance functions. IEEE Transactions on Pattern Analysis and Machine Intelligence, 17(7), 729-736. DOI. The quadratic histogram distance of QBIC and how to index it efficiently.

  • Stricker, M., & Dimai, A. (1996). Color indexing with weak spatial constraints. Storage and Retrieval for Still Image and Video Databases IV, SPIE Proceedings 2670, 29-40. DOI. Color moments per image region: the layout-aware remedy described in the color section.

  • Manjunath, B. S., & Ma, W. Y. (1996). Texture features for browsing and retrieval of image data. IEEE Transactions on Pattern Analysis and Machine Intelligence, 18(8), 837-842. DOI. The Gabor filter bank with mean and standard deviation features that became the standard texture descriptor.

  • Rui, Y., Huang, T. S., & Chang, S.-F. (1999). Image retrieval: Current techniques, promising directions, and open issues. Journal of Visual Communication and Image Representation, 10(1), 39-62. DOI. A survey of the first generation of content-based image retrieval.

  • Dalal, N., & Triggs, B. (2005). Histograms of oriented gradients for human detection. IEEE Conference on Computer Vision and Pattern Recognition (CVPR). PDF. The HOG descriptor with cells, blocks, and the design choices tested on pedestrian detection.

  • Lowe, D. G. (2004). Distinctive image features from scale-invariant keypoints. International Journal of Computer Vision, 60(2), 91-110. PDF. The full description of SIFT, including the ratio test and its 0.8 threshold.

  • Sivic, J., & Zisserman, A. (2003). Video Google: A text retrieval approach to object matching in videos. IEEE International Conference on Computer Vision (ICCV). PDF. Visual words, tf-idf, and inverted files for SIFT descriptors: text retrieval applied to images.

  • Szeliski, R. (2022). Computer vision: Algorithms and applications (2nd ed.). Springer. Free online edition. The standard textbook for edges, features, matching, and deep learning in vision.

  • Krizhevsky, A., Sutskever, I., & Hinton, G. E. (2012). ImageNet classification with deep convolutional neural networks. Advances in Neural Information Processing Systems (NeurIPS), 25, 1097-1105. NeurIPS proceedings. AlexNet, whose win in the ImageNet challenge of 2012 started the shift from hand-designed to learned features.

  • Zeiler, M. D., & Fergus, R. (2014). Visualizing and understanding convolutional networks. European Conference on Computer Vision (ECCV). arXiv. Shows what the layers of a trained CNN respond to, from edges to object parts.

  • He, K., Zhang, X., Ren, S., & Sun, J. (2016). Deep residual learning for image recognition. IEEE Conference on Computer Vision and Pattern Recognition (CVPR). arXiv. Introduces ResNet, including the ResNet-18 used in this chapter.

  • Razavian, A. S., Azizpour, H., Sullivan, J., & Carlsson, S. (2014). CNN features off-the-shelf: An astounding baseline for recognition. CVPR Workshops. arXiv. Shows that frozen CNN embeddings with a simple classifier beat hand-designed features on many tasks.

  • Babenko, A., Slesarev, A., Chigorin, A., & Lempitsky, V. (2014). Neural codes for image retrieval. European Conference on Computer Vision (ECCV). arXiv. CNN embeddings as image retrieval features, with and without fine-tuning.

  • Schroff, F., Kalenichenko, D., & Philbin, J. (2015). FaceNet: A unified embedding for face recognition and clustering. IEEE Conference on Computer Vision and Pattern Recognition (CVPR). arXiv. The triplet loss and face embeddings for verification, identification, and clustering.

  • Deng, J., Guo, J., Xue, N., & Zafeiriou, S. (2019). ArcFace: Additive angular margin loss for deep face recognition. IEEE Conference on Computer Vision and Pattern Recognition (CVPR). arXiv. The margin-based loss that succeeded the triplet loss for face embeddings.

  • Dosovitskiy, A., et al. (2021). An image is worth 16x16 words: Transformers for image recognition at scale. International Conference on Learning Representations (ICLR). arXiv. The Vision Transformer: images as sequences of patches.

  • Radford, A., et al. (2021). Learning transferable visual models from natural language supervision. International Conference on Machine Learning (ICML). arXiv. The CLIP paper, with extensive results on zero-shot transfer and linear probes.

  • Caron, M., Touvron, H., Misra, I., Jégou, H., Mairal, J., Bojanowski, P., & Joulin, A. (2021). Emerging properties in self-supervised vision transformers. IEEE/CVF International Conference on Computer Vision (ICCV). arXiv. Introduces DINO: self-distillation with a teacher and a student on crops of the same image.

  • Oquab, M., et al. (2024). DINOv2: Learning robust visual features without supervision. Transactions on Machine Learning Research. arXiv. Scales DINO to 142 million curated images and releases the models used in this chapter.

Libraries: OpenCV and scikit-image implement the classical features of this chapter (color conversions, Sobel, Gabor, HOG, SIFT); Hugging Face Transformers provides ResNet, CLIP, and DINOv2.
