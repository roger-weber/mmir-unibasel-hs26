Tasks and Experience

Where this is used

Classifiers detect the language of a query and route it in Intent Routing and Classification, and they turn images and audio into labels in Automated Feature Extraction. Self-supervised learning trains the word embeddings of Word Embeddings and the transformer encoders of Transformer Embeddings, and contrastive learning aligns images with their captions in Multimodal Transformers. The language models of 7 - Retrieval Augmented Generation and the speech recognizers of Transcription perform two of the tasks described below. reuses learned representations for a new task with only six labels.

Mitchell’s definition in A - Machine Learning Fundamentals names three ingredients of learning: a task TTT, a performance measure PPP, and experience EEE. This section covers the task and the experience: what we can ask a system to learn, and what it learns from. Losses and Performance Measures covers the performance measure.

Tasks¶

A task describes how the system should process an example, a set of features that we write as a vector x∈RM\mathbf{x} \in \mathbb{R}^Mx∈RM: the term weights of a document, the pixel values of an image, or the MFCCs of an audio frame. Learning is not the task itself but the means to perform it. The list below follows the catalogue in the deep learning textbook by Goodfellow, Bengio, and Courville (see Further Reading) and adds the tasks that appear in this book. Many more exist.

Classification maps an example to one of KKK categories: the system learns a function f:RM→{1,…,K}f: \mathbb{R}^M \to \{1, \dots, K\}f:RM→{1,…,K}. A common variant outputs a probability distribution P(y)P(y)P(y) over the KKK classes instead of a single class, with probabilities that sum to 1. Applications include object recognition in images, text categorization, spam filtering, handwriting and speech recognition, and credit scoring. In this book, classifiers detect the language of a query and route it to a backend (Intent Routing and Classification), and they turn images and audio into labels (Automated Feature Extraction).

Classification with missing inputs allows some features of an example to be absent. In disease prediction, the target “healthy” or “has the disease” depends on laboratory results, and since tests are expensive, not every patient has every result. A system that needs one function per subset of available features would need 2M2^M2M functions for MMM features. A better approach learns a probability distribution over all features and marginalizes out the missing ones, that is, it averages over all values they could take, weighted by their distribution in the training data. One model then serves every subset. Naive Bayes (Naive Bayes) handles missing features naturally: it chooses the class k∗=argmax⁡kP(Ck)∏iP(xi∣Ck)k^* = \operatorname{argmax}_k P(C_k) \prod_i P(x_i ∣ C_k)k∗=argmaxk​P(Ck​)∏i​P(xi​∣Ck​), and the product simply runs over the observed features only. Every task below has a similar variant with missing inputs.

Regression predicts a number: the system learns a function f:RM→Rf: \mathbb{R}^M \to \mathbb{R}f:RM→R. Unlike classification, the output is a real value, not a choice among categories and not a distribution over all possible values. Applications include forecasts, algorithmic trading, expected claims in insurance, financial risk assessment, budgeting, and pricing together with its effect on sales. Figure 1 contrasts the two tasks: in classification, the target is a label, drawn as a shape; in regression, it is a value on the vertical axis.

Clustering divides a set of examples into groups. Unlike classification, the groups are not known in advance, and the algorithm must discover them. Because there are no expected outputs, clustering is an unsupervised task, while classification and regression are supervised (see Experience below). Applications include genetic clustering, market segmentation into customer groups, communities in social networks, image segmentation, anomaly detection, and crime analysis. Clustering describes k-means and expectation maximization; Approximate Nearest-Neighbor Search uses k-means to compress vectors for search.

Density estimation constructs an estimate of an unknown probability distribution from examples. The system learns a function p:RM→Rp: \mathbb{R}^M \to \mathbb{R}p:RM→R, where p(x)p(\mathbf{x})p(x) is a probability density for continuous x\mathbf{x}x or a probability mass function for discrete x\mathbf{x}x. The simplest estimator is a histogram. Figure 2 estimates the same distribution with wide and with narrow bins. Wide bins smooth away detail, and narrow bins show spikes that come from the particular sample rather than from the distribution. The bin width is a first example of the capacity of a model, which returns in Over- and Underfitting. Applications include the age distribution of a country, feature extraction, and the simplification of models. Density estimation is also a building block of other tasks: anomaly detection flags examples with a low density, and classification with missing inputs marginalizes over a learned density.

Imputation of missing values replaces missing data with estimated values. Given an example x∈RM\mathbf{x} \in \mathbb{R}^Mx∈RM with some entries xix_ixi​ missing, the system predicts the missing entries. Applications include incomplete sensor data, incomplete personal records in demographics, medical analysis with missing or expensive tests, and signal restoration after data loss.

Anomaly detection identifies unusual, incorrect, or atypical events. The output is a flag, 1 for an anomaly and 0 otherwise, or a probability of an anomaly. Supervised anomaly detection learns from examples labeled “normal” and “abnormal”. Unsupervised anomaly detection describes the normal behavior, for example with a density estimate, and flags the examples that deviate from it. Applications include credit card fraud detection, intrusion detection, removing outliers before a statistical analysis, change detection, system health monitoring, and fault detection.

Generation produces new examples that resemble the training data: images, text, music, or program code. The model captures the patterns of the training data and samples new instances with similar characteristics. Generative models usually learn without manual labels, through self-supervised learning (see Experience below). Applications include image synthesis, text generation, style transfer, data augmentation, chatbots, code assistants, assets for games, and summarization. The language models that write the answers in 7 - Retrieval Augmented Generation belong here.

Machine translation maps a sequence of symbols in one language to a sequence in another. Translating word by word is not enough; the system must find a representation that is structurally and semantically correct in the target language.

Transcription converts unstructured data into a discrete, usually textual form. Optical character recognition and speech recognition (Transcription) are the best-known examples.

Dimensionality reduction maps examples to a space with fewer dimensions. The new dimensions can often be read as topics, concepts, or embeddings, which makes it easier to find documents on similar topics. Principal component analysis and latent semantic indexing (Latent Semantic Indexing) are classic methods; the embeddings of Word Embeddings are learned ones. Other uses include data mining, statistical analysis, and compression.

Reasoning derives conclusions from knowledge with logical techniques such as deduction and induction. Knowledge-based systems, for example expert systems written in Prolog, use facts and rules to prove or disprove statements within a closed world. Machine learning now supports theorem proving and constraint solving, and large language models produce intermediate reasoning steps before an answer, which improves their results on problems that need several steps.

Autonomous agents, such as robots and self-driving cars, act in an environment and adjust their behavior to rewards and penalties, which is reinforcement learning (see Experience below). They must decide in situations that their programmers could not anticipate or hard-code. This raises questions of machine ethics: when a collision with an animal or a person is unavoidable, should the car risk an evasive maneuver that endangers its passengers? Liability for mistakes, safety, privacy, and the hacking of vehicles remain open questions for law and society.

Experience¶

The experience is the data that the system observes during training and what it is told about that data. The types of experience differ in the feedback they provide: correct outputs, outputs for some examples only, no outputs, rewards, or outputs taken from the data itself.

Supervised Learning¶

A supervised learning algorithm observes a dataset of features together with their targets. It learns a general rule that maps features to targets, so that it can predict the targets of new examples. The term comes from the idea of a teacher who provides the targets and so shows the algorithm how features map to labels. Figure 1 shows both kinds of targets. The goal is not to reproduce the targets of the training set but to generalize to new data. The teacher therefore usually provides a performance measure along with the labels, which checks how well the rule generalizes. Over- and Underfitting explains why the two goals differ.

Labels are expensive. Creating them is laborious work, much like producing metadata for a collection (Metadata and Its Limits). This motivates approaches that need fewer labels or none: semi-supervised and self-supervised learning.

Semi-Supervised Learning¶

In semi-supervised learning, only some training examples have targets. In credit card fraud detection, for example, only the transactions that were investigated carry the label “fraud” or “no fraud”, and the vast majority remains unlabeled. To learn from such data, algorithms make assumptions about how the labels relate to the distribution of the features:

  • Smoothness: points close to each other share the same label, so the label changes smoothly across the feature space.

  • Cluster: the data forms clusters, and all objects in a cluster share the same label.

  • Manifold: the features are high-dimensional, but the data lies close to a low-dimensional manifold.

Figure 3 contrasts two ways to use the unlabeled points. Induction learns a general rule that labels any new point. Its simplest form trains a supervised model on the labeled examples and applies it to the unlabeled ones. This works when only a few labels are missing. When most labels are missing, the labeled part is too small to capture the distribution of the labels, and the approach ignores most of the data.

Transduction has a narrower goal: it learns no rule for points that arrive later, but only predicts the labels of the unlabeled points already in the dataset. For this, it uses the positions of all points, labeled and unlabeled, because together they show where the clusters are. A simple partitioning method builds the clusters as follows. It starts with one cluster that contains all objects. While a cluster contains two labeled objects with different labels, it splits the cluster to resolve the conflict. Finally, it gives every unlabeled object the label of the labeled objects in its cluster. Many variants exist for building the clusters.

Unsupervised Learning¶

Unsupervised learning algorithms observe data without targets and derive a function that describes its structure or distribution. No teacher provides targets or evaluates the result; the algorithm must find meaningful patterns on its own. Figure 4 shows the two most common findings, a cluster and an outlier. Typical tasks are:

  • Clustering: find groups of similar objects based on a distance function. The number of groups is often unknown.

  • Outlier and anomaly detection: learn the normal behavior and identify the objects that deviate strongly from it. The training data may itself contain outliers.

  • Density estimation: describe the data with a density function, from a single Gaussian to the best fit among several families of distributions.

  • Dimensionality reduction: extract the core concepts of high-dimensional features, for example with principal component analysis, for a simpler yet accurate view of the data.

  • Self-organizing maps: map high-dimensional data onto a two-dimensional grid by competitive learning.

Reinforcement Learning¶

Reinforcement learning receives neither targets nor data alone, but rewards for its actions; Losses and Performance Measures describes how the reward function serves as its performance measure. One prominent use connects it with language models. In reinforcement learning from human feedback, people rank several answers of a model, a reward model learns these preferences, and reinforcement learning then tunes the language model to produce answers with a high reward (Ouyang et al., see Further Reading).

Self-Supervised Learning¶

Self-supervised learning takes the targets from the data itself. It hides part of an example and trains the model to predict the hidden part from the rest. No manual labels are needed, so the model can learn from collections with billions of examples. Technically, it is supervised learning with free labels. Several models in this book learn this way. Word2vec predicts the words around a center word (Word Embeddings). BERT masks 15% of the tokens of a sentence and predicts them from the context (Transformer Embeddings), and generative language models predict the next token. Contrastive learning pairs data from different modalities: CLIP learns that an image and its caption from the web belong together (Multimodal Transformers). Pairs collected from the web are noisy, so this setting is also called weak supervision.

Learned representations, whether they come from supervised or self-supervised training, serve new tasks with few labels. trains a classifier on frozen image embeddings with only six labeled photos.

Generative adversarial networks, introduced by Goodfellow and colleagues in 2014, also create their own labels. Figure 5 shows the two networks. A generator turns random noise into a sample, for example an image. A discriminator receives real samples from the dataset and generated ones and predicts for each whether it is real or generated. The labels “real” and “generated” come for free. The two networks compete: the generator learns to make the discriminator wrong, and the discriminator learns to tell the two kinds of samples apart. Diffusion models have since replaced generative adversarial networks in most image generators.
