# Exercise 11: Audio Features

> **Chapter:** Ch11 - Audio Features · **Estimated time:** ~20 minutes · **Optional:** no submission, no grading

This chapter has no exercise notebook. It follows audio from the waveform to the spectrogram, then to perceptual features such as MFCCs, musical features such as chroma, pitch, and tempo, speech/music classification with decision trees, pretrained classifiers, and CLAP, transcription with Whisper and LLM-based recognizers, and audio fingerprinting for song recognition.
